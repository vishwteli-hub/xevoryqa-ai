
# XEVORYQA AI

### AI-Powered Suspicious Message Detector

XEVORYQA AI is an AI-powered web application that helps identify potentially suspicious SMS messages and online communications.

## Features

- Machine Learning-based spam detection
- Suspicious message risk assessment
- Detection of suspicious links and warning signs
- AI-powered explanations using Google Gemini
- Practical safety recommendations
- Responsive design for mobile and desktop

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Logistic Regression
- Google Gemini API

## Model Performance

Achieved 97.67% accuracy on a held-out test set from the SMS Spam Collection dataset.

This result does not guarantee real-world detection accuracy.

## Run Locally

Install dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py

Configure your Gemini API key securely using the GEMINI_API_KEY environment variable.

## Disclaimer

XEVORYQA AI provides an initial risk assessment, not definitive proof of fraud.

Never share OTPs, passwords, or banking credentials with suspicious sources.
